## The Problem

Traditional earth science workflows are slow, siloed, and dependent on scarce domain expertise. GEOX encodes that work into a system that can:

- Process seismic and interpret structures with physics guards
- Run petrophysics on LAS consistently
- Profile basins from local evidence (Malay Basin is the richest local pack)
- Assess geohazards (GLOF cascade family) without pretending to be a court
- Query paleobiology with spatial-temporal context
- Observe Earth **images** (outcrop, core, fossil, seismic display) under a strict evidence-only rule — see [Images & multimodal](#images--multimodal)

It will also **refuse**. A 33° map bbox is too big — that is a design constraint, not a crash. Macrostrat 500 is "no data," not a fabricated column. Empty SUCCESS is a lie; GEOX is not allowed to stamp `ok: true` on an empty basin envelope.

## Epistemic labels

## What GEOX refuses, and what it cannot know

**Refusals (failure model):**

- GEOX will not return `ok: true` on an empty basin envelope. Empty SUCCESS is a lie.
- GEOX will not fabricate a claim for a 33° map bbox — that is a design constraint, not a crash.
- GEOX will not paper over Macrostrat 500 — that is "no data," not a fabricated column.
- GEOX will not raise a verdict — it issues signals only. arifOS seals.
- GEOX will not propagate ghost capabilities. Surfaces are gated (`SURFACE_DRIFT` middleware); raw_live > canonical means the runtime hasn't caught up — **redeploy**, do not paper over.
- GEOX will not turn an image into a specimen. `Image ≠ Specimen ≠ Measurement ≠ Earth` — see [Images & multimodal](#images--multimodal).

**Physics limits (what no computation can overcome):**

| Limit | Consequence |
|---|---|
| Non-uniqueness | Many earth models fit the same data. GEOX returns the candidate set with falsifiers, never "the" answer |
| Tuning / resolution | Seismic resolution is tens of metres at best; thin beds below tuning thickness are invisible, not absent |
| Time ≠ depth | TWT sections are not geometry until velocity-calibrated; unconverted depth claims are refused |
| Fluid ambiguity | Fizz gas (low saturation) and commercial gas produce nearly identical amplitude. Amplitude ≠ hydrocarbon — enforced in code (`I3`) |
| Equifinality | Different processes produce identical geology (e.g. mobile-shake accommodation vs tectonic unconformity). GEOX labels which processes could produce the observation |
| Sparse wells | One well is a point, not a field; properties between wells are DER/SPEC, never OBS |
| Erased time at unconformities | Unconformities delete record; absence of evidence across them is not evidence of absence |

A reply that claims to overcome any of these has failed the constitution.

## RT1 recovery

RT1 rejects a tool name that is not on the canonical surface. The recovery suggestion is **derived from the registry at call time** (`registry.py::derive_recovery_tool`), never a hardcoded string — a literal recommendation is an unfalsifiable claim that silently goes stale. The invariant `recommended_next ⊆ callable_surface` is enforced in `geox_middleware.py`; if nothing qualifies, the response carries `recommended_next: null` and says the registry is defective — it never invents a name. Covered by `tests/test_rt1_recovery_derivation.py` (18 tests), including a no-literal regression guard.

## Authority floor

Every tool has a minimum required authority band (`OBSERVE_ONLY < OPERATOR < LIMITED_MUTATE < FULL < SOVEREIGN`); the connector admits or rejects on the session token's band.

| Action class | Required authority |
|---|---|
| `OBSERVE` | `OBSERVE_ONLY` |
| `MUTATE` | `LIMITED_MUTATE` |
| `EXECUTE` | `LIMITED_MUTATE` |

**Writes, stated precisely.** GEOX is not "never writes": two tools mutate *local* state — `geox_well_ingest` with `overwrite=true` (writes the **local GEOX ingest workspace**, e.g. `/data/wells` inside this deployment) and `geox_claim` in `seal` mode (records a claim-state transition in GEOX's **local claim ledger**; it is gated — well-constrained evidence required — and remains an *organ-local* record). What GEOX **never** writes: federation databases, VAULT999, arifOS state, or anything outside its own workspace. Constitutional `SEAL` verdicts belong to arifOS's `arif_judge` alone — `geox_claim(mode='seal')` is bookkeeping, not judgment. Escalations beyond local mutation require arifOS + A-FORGE + the sovereign.

**Resource estimates, stated precisely.** `geox_prospect` computes volumetrics / POS / EVOI as **DER/SPEC advisory ranges** passed (with uncertainty) to the WEALTH organ and the claim engine. They are **not booked resources** — reserve booking is a WEALTH + human institution act. `geox_temporal`'s decline curves and RRR are analytic aids on supplied production data; whether they belong in GEOX or WEALTH long-term is a held ownership decision (see Open defects).

GEOX sits at plane **L3 DOMAIN** under `arifOS`. The contract:

1. **arifOS** owns judgment. Every GEOX claim is `OBS` / `DER` / `INT` / `SPEC` / `UNKNOWN` and travels with provenance. arifOS's `arif_judge` is the only path to SEAL.

4. **WELL** owns the substrate mirror. GEOX emits ΔS entropy events that WELL ingests.
