# Fault Inheritance Analysis

## Core Principle

Fault age must be derived from relational evidence, not azimuth alone. (SR_INV_008, TECT-004)

## Required Evidence Fields

For every fault in a restoration scenario:

- **Fault ID** — unique identifier
- **Mapped azimuth** — present-day strike (evidence, not age)
- **Cross-cutting relationship** — does this fault cut or is it cut by others?
- **Bend or termination** — does it bend along or terminate against older structures?
- **Continuity and segmentation** — is it continuous or segmented?
- **Displacement evidence** — how does displacement change along strike?
- **Associated basement trend** — does it align with gravity/magnetic basement fabric?
- **Stress-model comparison** — does its orientation match the expected stress field?
- **Proposed generation** — which tectonic event created it?
- **Confidence** — how confident is the generation assignment?
- **Alternatives** — what other generations are possible?

## Rules

1. Fault azimuth alone NEVER determines generation
2. Cross-cutting relationships are the strongest evidence
3. Bending along older structures indicates inheritance
4. Two NE-SW faults can have completely different ages, drivers, and petroleum implications
5. Stress orientation is a QC constraint, not a forced answer (SR_INV_014, EUREKA-06)

## NW Sabah Fault Generations

| Generation | Age Range | Stress Regime | Typical Orientation |
|-----------|-----------|---------------|---------------------|
| Syn-rift (ASAS/BEBAS) | Paleogene | N-S extension | NE-SW to E-W |
| Collision (KAPUR) | ~23 Ma | NW-SE compression | NE-SW (thrust) |
| Slab breakoff (SABAR) | ~13 Ma | Post-collisional rebound | Variable |
| Gravity-driven (SENJA) | Post-10.5 Ma | Gravity + compaction | Downslope trends |

**Warning:** Present-day azimuth does not map uniquely to generation. Relational evidence is required.
