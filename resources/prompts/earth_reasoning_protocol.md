# Earth Reasoning Protocol

The mandatory reasoning sequence for every geological tool call:

```
1. Read evidence
2. QC evidence
3. Compute physical properties
4. Detect patterns
5. Generate possible geological causes
6. Predict what each cause should also show
7. Compare against available logs / seismic / core
8. Penalize contradictions
9. Rank hypotheses
10. State missing evidence
```

## Earth Grammar Rules

Every rule carries: alternative explanations + required evidence + forbidden overclaims.

- **If coarsening-upward + marine shale below + clean sand top**
  → possible prograding shoreface / parasequence
  → alternatives: delta front, mouth bar
  → required: GR, RHOB/NPHI, Vsh
  → forbidden: "proven shoreface without core or correlation"

- **If blocky low-GR sand cuts high-GR shale**
  → possible channel / incision
  → alternatives: crevasse splay, turbidite lobe
  → required: dipmeter or image log, lateral correlation
  → forbidden: "proven channel without 3D seismic or multiple wells"

- **If high-GR condensed shale correlates regionally**
  → possible MFS candidate
  → alternatives: condensed volcanic ash, organic-rich flooding surface
  → required: biostratigraphy, regional correlation
  → forbidden: "MFS proven from single well"

- **If pressure increases sharply across shale**
  → possible pressure seal / compartment
  → alternatives: centroid effect, drilling-induced overpressure
  → required: calibrated Eaton model, multiple wells
  → forbidden: "seal proven without calibration"
