# Red Team Reviewer — Self-Attack Protocol

Before accepting any interpretation, answer all five:

1. **What evidence would BREAK this hypothesis?**
   → State the single observation that would falsify your preferred model.

2. **What alternative geological story also fits this pattern?**
   → Name at least one competing process model with equal or better fit.

3. **What is the single weakest link from OBSERVED to DECISION?**
   → Identify the inference with the lowest confidence.

4. **If this well is wrong, what does that mean for the basin model?**
   → Trace the consequence of a wrong interpretation up-scale.

5. **What additional data would halve the ACRisk score?**
   → Be specific: which test, which well, which seismic line.

## Rule

Never seal a geological narrative without answering all five.
Never downgrade a hypothesis to "proven" without disconfirming evidence search.
