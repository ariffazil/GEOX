01 Endpoints

All GEOX tools are exposed through a single Model Context Protocol surface. Transport: HTTP and stdio. Auth: session-token gated at the federation boundary.

02 Sample Invocations

Ingest a well log

// MCP tool call — tools/call
{
  "method": "tools/call",
  "params": {
    "name": "geox_well_ingest",
    "arguments": {
      "mode": "auto",
      "source_uri": "/data/wells/marmousi-1.las",
      "well_id": "MARMOUSI-1",
      "standardize_curves": true,
      "qc_strict": true
    }
  }
}

Compute petrophysics

{
  "method": "tools/call",
  "params": {
    "name": "geox_petrophysics",
    "arguments": {
      "mode": "generate",
      "well_id": "MARMOUSI-1",
      "depth_top_m": 2200,
      "depth_bot_m": 2400,
      "archie_a": 1.0,
      "archie_m": 2.0,
      "archie_n": 2.0,
      "rw_ohm_m": 0.05
    }
  }
}

Create an interpretation claim

{
  "method": "tools/call",
  "params": {
    "name": "geox_claim",
    "arguments": {
      "mode": "create",
      "claim_text": "Interval 2200-2400 m MD may be clean sand; candidate net reservoir.",
      "claim_type": "interpretation",
      "truth_class": "INTERPRETATION",
      "evidence_ids": ["petro:MARMOUSI-1:2300", "logs:MARMOUSI-1:GR"],
      "uncertainty_p50": 0.62,
      "uncertainty_p90": 0.85,
      "alternatives": [
        {"text": "Tight streak — log effect only", "p": 0.18},
        {"text": "Fresh water — low resistivity", "p": 0.12},
        {"text": "Processing artifact", "p": 0.08}
      ]
    }
  }
}

04 Failure Contract

Every GEOX tool returns one of three outcomes. There is no fourth "successfully failed" state.

PASS — claim grounded, evidence attached, alternatives registered, uncertainty banded.
888_HOLD — claim awaits human ratification. No irreversible action may proceed.
VOID — claim cannot be grounded. Returns the contradiction or missing evidence.

When you call a tool, you are not asking GEOX "what do you think". You are asking it "show me the evidence". The tool will return either the evidence, a HOLD, or a VOID — never an ungrounded assertion.
