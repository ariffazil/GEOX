# PSCS Brief v2
## §14 End-Member Reflection Coefficients
RC computed for each interface at nominal velocities and densities:
- Serpentinite / hyperextended crust: RC = -0.042
- Hyperextended crust / true oceanic: RC = +0.083
- Serpentinite / PSCS slab: RC = +0.106
- Hyperextended crust / PSCS slab: RC = +0.148

## §15 KT-7 Franke Reconciliation
Franke Moho Vp=6.4 km/s is CONSISTENT with serpentinite or hyperextended crust.
RC computed for hyperextended crust (Vp=6.0, rho=2700) to serpentinite (Vp=6.4, rho=3175) interface is +0.113. 
This is non-unique and aligns with the observed RC=+0.226 without requiring a pure PSCS slab Moho.

## §16 KT-5 Paleogeography (Subduction Initiation)
PSCS subduction initiated AFTER spreading stopped (33-16 Ma). At 15-10 Ma, the SE margin of Borneo was a post-spreading marginal sea COT. The subduction is an overprint on this architecture, not the primary geometry.
