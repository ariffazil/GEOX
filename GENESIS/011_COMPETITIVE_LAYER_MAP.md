## 1. False premise (Opencode error)

**Wrong framing:**

```text
Halliburton's Geosciences Suite is what GEOX would compete against directly —
scalable earth modeling, basin-to-field, ensemble workflows.
```

**Half true, half wrong.** True: Halliburton competes in *geoscience workflow territory*. Wrong: GEOX and DSG are the same class of thing.

| Class | What it is |
|-------|------------|
| **DSG / DS365** | Machine-assisted interpretation *management* — workflows, stores, models, ensembles, enterprise team glue |
| **GEOX** | Earth-truth *reasoning infrastructure* — evidence discipline, falsification, uncertainty class, lineage, OBS/DER/INT/SPEC |

A “single live earth model” is not the earth. It is a **synchronized interpretation object**.

---

## 2. What DSG can hold vs what intelligence requires

DSG can hold:

```text
fault polygons · horizons · seismic volumes · well tops
reservoir grids · properties · ensembles · uncertainty cases · production
```

Unless it can say:

```text
this interpretation is weak
this horizon pick is contradicted by well control
this basin model violates thermal maturity evidence
this prospect works only if assumption X survives
this uncertainty is epistemic, not stochastic
this model should be killed
```

…it is not intelligence. It is a **high-end filing cabinet with simulation buttons**.
