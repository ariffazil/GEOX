> **GEOX witnesses the Earth. It does not interpret it.**

## 1. The Line

| GEOX Witnesses (In) | GEOX Does Not Do (Out) |

## 2. Output Rule

GEOX tools return **plain physics-derived facts**. Enrichment (claim tags, governance status, audit receipts) is added by the transport layer, not by the tool implementation.

## 3. Physics-9 Orthogonality

Nothing outside `geox_core.physics/` defines new physics parameters. All engines read from and write back to this layer.
