# Security Policy

## Supported Versions

Only the latest release of GEOX is active and supported for security updates.

| Version | Supported |
| ------- | --------- |
| Latest  | ✅ Yes     |

## Reporting a Vulnerability

We take the security of GEOX seriously. If you find a security vulnerability, please do not open a public issue. Instead, report it directly to the Sovereign:

- **Email:** ariffazil@gmail.com
- **Response SLA:** Within 48 hours for triage and initial assessment.

Please include:
1. A description of the vulnerability and its potential impact.
2. Step-by-step instructions or a proof-of-concept (PoC) to reproduce the behavior.
3. Any suggested mitigations.
